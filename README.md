\# AI Hospital Intelligence



\## AI-Driven Predictive Data Mining for 30-Day Hospital Readmission and Hospital Resource Optimization



This project develops an AI-driven hospital decision-support system combining:



\- 30-day hospital readmission prediction

\- Explainable AI using SHAP

\- Hospital resource demand forecasting

\- Resource optimization

\- Integrated hospital intelligence dashboard



\## Technology Stack



\- Python

\- Scikit-learn

\- XGBoost

\- LightGBM

\- CatBoost

\- SHAP

\- FastAPI

\- PostgreSQL

\- React

\- TypeScript

\- Tailwind CSS

\- OR-Tools / PuLP
